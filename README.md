# *Proyecto SPA - GlowQueen*

***¡Hola a tod@s! Este repositorio contiene la entrega del proyecto CSS enfocado en el desarrollo de la sección **header-hero** para una página web relacionada con un negocio de tipo **SPA**.***

## *✅✨ Requerimientos del Proyecto*

***El desarrollo se ha realizado siguiendo estrictamente las siguientes especificaciones:***

*   **Boilerplate:** Utilizado como punto de partida preferido para la inicialización del entorno.
*   **Uso de SASS:** Implementado para mejorar la organización, modularidad y mantenibilidad del código (estructurado en directivas `base` y `components`).
*   **Diseño estático:** Enfocado en una resolución fija de *1440 x 900*, asegurando que se visualice exactamente igual que en el diseño de referencia.
*   **Recursos de diseño:** Assets y componentes exportados directamente desde el archivo oficial de *Figma*.
*   **Iconos en SVG:** Uso preferente de vectores en formato *SVG* para garantizar nitidez visual en lugar de imágenes rasterizadas.
*   **Semántica:** Estructura limpia utilizando etiquetas semánticas de HTML5 para una correcta jerarquía del documento.
*   **Fidelidad al diseño:** Acabado idéntico y con la máxima precisión respecto a la versión estática entregada.
*   **Interactividad:** Todos los elementos interactuables (como los botones *Book Now*, *Sign In*, *Sign Up*, enlaces de navegación y flechas) cuentan con sus respectivos estados `hover`.
